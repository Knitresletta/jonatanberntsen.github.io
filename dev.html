Produkter

UlRemedyForever ↗ CurseForge ↗ GitHub

Quality-of-life-samling for World of Warcraft: Forever. Over femten små verktøy i ett tillegg, fra auto-reparasjon og større vendorvindu til auksjonspriser i tooltips som deles mellom brukere over en skjult chatkanal. README-en sier nøyaktig hva som forlater maskinen din. Versjon 1.20, publisert på CurseForge.

Lua WoW API CurseForge
UlDungeonCompanion ↗ CurseForge ↗ GitHub

Finner dungeons, dungeon-quests og elite-quests som passer nivået ditt, og viser dem på verdenskartet og i et eget vindu. Datagrunnlaget bygges med Python-verktøy fra 1.12-databasen og community-kilder, og sjekkes mot serveren i spillet.

Lua Python Datapipeline
UlSource ↗ CurseForge ↗ GitHub

Hvor kom dette fra? Registrerer hvert loot med kilde, sone og posisjon, og viser dropprater og funnsteder i tooltip og på kartet. En database som vokser for hver gang du looter, uten ferdigdata og uten nettverk.

Lua SavedVariables WoW API
Garderobe ↗ Prøv den ↗ GitHub

PWA for å fotografere plagg, sette dem sammen til looks og lagre alt lokalt på telefonen. Ingen server, ingen konto. IndexedDB, service worker, bakgrunnsfjerning i canvas og sikkerhetskopi som JSON.

JavaScript PWA IndexedDB
UlRemedy ↗ GitHub

Retail-utgaven og opphavet til Forever-familien. Auto-reparasjon, keystone-lenking, søppelsalg og bankinnskudd. Alt det kjedelige, automatisk.

Lua WoW API
KeyLink ↗ GitHub

Ett Lua-skript, én jobb: når noen skriver !keys i gruppe-, raid- eller instance-chat, finner tillegget Mythic Keystone-en din i veskene og lenker den i samme kanal. Retail-tillegg på førti linjer.

Lua WoW API
klasserom-dashboard ↗ GitHub

Vanilla HTML/CSS/JS klasseromsdashboard: navnetrekning, tilstedeværelse, nedtelling og dagsplan. Kjører i nettleseren, lagrer tilstand i localStorage.

sjaforkalkulator ↗ GitHub

Mobil-først kalkulator for kjørekostnader: drivstoff og slitasje, med tur/retur og spleis. Bygget som PWA, kjører rett i nettleseren.

JavaScript PWA HTML / CSS
ateroids ↗ GitHub

Asteroids bygget i Pygame. Objektorientert spill-loop med kollisjoner, asteroidefelt og egen logger. Boot.dev-prosjekt.

kodekurs ↗ GitHub

Åpent kursmateriell for koding for barn og ungdom 10-16 år: tre språkspor (Python, Scratch og Lua/Roblox), bygget som en stige av 45-minutters segmenter med oppgaver i tre nivåer og byggeøkter uten fasit. Markdown i repo, så andre instruktører kan forke og tilpasse.

Markdown Python Scratch Lua / Roblox
